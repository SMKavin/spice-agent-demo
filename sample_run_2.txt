### 1. Theory (initial estimate)

For a first‑order low‑pass, the –3 dB frequency is  

\[
f_c = \frac{1}{2\pi R_{\text{eq}} C}
\]

where \(R_{\text{eq}}\) is the resistance “seen” by the capacitor.  
Ignoring the load (10 kΩ ≫ R), we started with  

\[
R_{\text{eq}} \approx R_{\text{source}}+R = 600\;\Omega + R
\]

Choosing a standard capacitor 0.22 µF gave an initial target resistance  

\[
R_{\text{eq}} \approx \frac{1}{2\pi f_c C}
            = \frac{1}{2\pi(1\text{kHz})(0.22\;\mu\text{F})}
            \approx 724\;\Omega
\]

Thus we needed a series resistor ≈ 124 Ω → the nearest E‑12 value is **120 Ω**.  
The first simulation with 120 Ω gave a measured cutoff of 1.076 kHz (≈ 7.6 % high), so we refined the values.

---

### 2. Simulation & Iteration

All simulations were run with **ngspice** using an AC sweep and a `.meas` command that finds the frequency where the output magnitude equals the low‑frequency magnitude divided by √2 (‑3 dB).  

Because the low‑frequency gain is not unity (the 10 kΩ load forms a divider with the source resistance), the target magnitude is:

\[
V_{\text{target}} = \frac{R_{\text{load}}}{R_{\text{load}}+R_{\text{total}}}\;\frac{1}{\sqrt{2}}
\]

The netlist template used for every run was:

```spice
* RC low‑pass filter – iteration #
V1 in 0 AC 1
Rsource in n1 600
Rseries n1 out <R_series>
C1 out 0 0.22u
Rload out 0 10k
.control
ac dec 100 10 100k
meas ac f3db when vm(out)=<V_target>
.endc
.end
```

|--------------|----------------|------------|---------------|----------------------|--------------------|
| 1 (initial) | 120 | 720 | 0.933 | 0.660 | **1 075.9** |

| 4 (final) | **180** | **780** | **0.927** | **0.656** | **999.65** |

The fourth iteration satisfied the spec:

\[
\text{Error} = \frac{f_{3dB}-f_{\text{spec}}}{f_{\text{spec}}}\times100
            = \frac{999.65-1000}{1000}\times100
            = -0.035\%
\]

which is **well within the ±0.5 % requirement**.
